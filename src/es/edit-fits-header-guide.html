⚠️ Problemas Reales Comunes en Cabeceras FITS

Tanto si captura con N.I.N.A., ASIAIR o software de observatorio, es habitual que falten datos esenciales:

❌ Falta o Error en BAYERPAT

Las cámaras a color (OSC) requieren la clave BAYERPAT (ej. RGGB, BGGR). Si falta, Siril o PixInsight producen imágenes monocromáticas o colores invertidos.

Solución: Modifique o añada la clave BAYERPAT según el patrón exacto de su sensor.

❌ Fallos de Plate-Solving (WCS / Escala)

Los resolvedores de campo (ASTAP, ASTROMETRY.NET) fallan si la distancia focal (FOCALLEN) o el tamaño de píxel (PIXSIZE) son cero o incorrectos.

Solución: Inserte los valores ópticos exactos en milímetros y micrómetros.

❌ Etiqueta FILTER Ausente en Monocromo

En sesiones LRGB o banda estrecha, una pérdida en la etiqueta FILTER puede hacer que el software mezcle tomas de Halfa con Luminancia.

Solución: Asigne el nombre del filtro (ej. Ha 3nm, OIII) a cada toma.

❌ Tiempo de Exposición EXPTIME en Cero

Al ponderar imágenes durante el apilado, un valor erróneo distorsiona el cálculo del ratio señal/ruido.

Solución: Calibre el tiempo de exposición numérico en segundos.

📖 Tabla de Referencia de Palabras Clave FITS

Referencia de consulta para asegurar el cumplimiento con el estándar astronómico internacional:

Palabra Clave FITS Tipo de Dato Valor de Ejemplo Función Científica y Descripción
SIMPLE Booleano T Indica si el archivo cumple estrictamente el estándar FITS. Debe ser la primera tarjeta.
BITPIX Entero 16 / -32 Bits por píxel de datos (16 = entero corto; -32 = coma flotante IEEE).
NAXIS Entero 2 (o 3) Número de ejes coordenados (2 para imagen 2D; 3 para cubos de datos o RGB).
OBJECT Texto 'M42 Orion' Nombre del objeto celeste fotografiado para catalogación y archivo.
EXPTIME Decimal / Número 300.0 Duración de la exposición medida en segundos.
FILTER Texto 'Ha', 'OIII' Filtro óptico utilizado durante la adquisición del cuadro.
BAYERPAT Texto 'RGGB' / 'BGGR' Patrón de matriz de color necesario para un debayerizado correcto.
FOCALLEN Decimal / Número 800.0 Distancia focal efectiva del telescopio o lente en milímetros (mm).
PIXSIZE Decimal / Número 3.76 Tamaño físico de cada píxel del sensor en micrómetros (μm).
GAIN Entero / Decimal 100 Ganancia del sensor empleada durante la captura.
