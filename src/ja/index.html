📌 要点まとめ（E-E-A-T エグゼクティブサマリー）

FITS（Flexible Image Transport System）は、1981年以来、天文学における世界共通のデータ標準フォーマットです。すべての天体画像や分光データには、座標、センサーゲイン、フィルター、光学系を記録した80文字単位の標準カードが含まれています。

結論： カードの確認、プレートソルブ失敗の診断、欠落したメタデータ（OBJECT、EXPTIME、FILTERなど）の修正のみを行う場合、1.5GBを超えるPixInsightの起動やPython環境の構築は過剰です。FITS Header Editor Onlineなら、インストール不要・サーバー送信なしで、ブラウザ内で100%安全かつ即座に処理が完了します。

🔍 ステップ1：FITSヘッダーを即座に確認する

スタックソフト（Siril、DeepSkyStackerなど）で位置合わせに失敗した場合、最初の原因調査はヘッダーの確認です：

  1. FITS Header Editor Online を開きます。
  2. FITSファイル（.fits、.fit、.fts）を点線枠内にドラッグ＆ドロップするか、Select FITS File をクリックします。
  3. お試し用の場合は、Load Sample FITS をクリックしてサンプルデータ（13838SgrA.fits）を読み込みます。
図1：サーバーへのアップロード不要で安全にファイルを読み込める画面。

✏️ ステップ2：ヘッダーカードの編集・追加・並べ替え

読み込み後、標準80桁のFITSカードが一覧表示されます：

図2：リアルタイム検索、カテゴリ別絞り込み、クイックボタンを備えたエディター画面。

便利な操作方法：

  • 即時検索：検索バーにキー名（例: CRVAL1）や値を入力するだけで素早くカードを抽出できます。
  • 安全なインライン変更：ブール値はドロップダウン（T (True) / F (False)）で切り替え可能。文字列や数値も桁あふれを防止します。
  • クイック追加：上部の + OBJECT、+ FILTER、+ BAYERPAT などのボタンを押すだけで標準キーを自動挿入できます。
  • 並べ替えと削除：右側の ↑ / ↓ で順序を変更し、✕ で不要なカードを削除できます。

修正したファイルの保存：

編集完了後、Save & Download FITS をクリックすると、2880バイト単位に整形されたヘッダーと画像データが結合され、標準規格に準拠した .fits ファイルがダウンロードされます。
