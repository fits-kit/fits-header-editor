⚠️ 实际拍摄中常见的文件头损坏场景

无论您使用的是 N.I.N.A.、ASIAIR、KStars/Ekos 还是天文台自研拍摄终端，设备驱动异常或配置失误经常导致关键元数据缺失：

❌ BAYERPAT 拜耳阵列缺失或识别错误

彩色天文相机（OSC）需要依赖 BAYERPAT（如 RGGB、BGGR）。若该卡片缺失，Siril 或 PixInsight 在去马赛克后将输出偏色或单色画面。

解决方法：在编辑器中添加或修改 BAYERPAT 为感光元件对应的阵列名称。

❌ 盲解算（Plate Solving）失败

解算软件（ASTAP、ASTROMETRY.NET）在望远镜焦距（FOCALLEN）或像元尺寸（PIXSIZE）为 0 或记录错误时无法推断视场。

解决方法：直接在卡片表格中补全焦距与像元微米数值。

❌ 多通道拍摄中丢失 FILTER 标签

黑白冷冻相机拍摄 LRGB / 窄带序列时，若滤镜轮通信异常可能遗漏 FILTER，导致批处理堆栈软件将 Ha 误并入亮通道。

解决方法：为对应的单帧子图补充确切的滤镜名称（如 Ha 3nm、OIII）。

❌ 曝光时间 EXPTIME 记录为 0

在根据信噪比权重进行 Sigma-Clipping 堆叠时，错误的曝光时间会严重干扰算法权重的分配。

解决方法：以秒为单位校正数值型曝光时间字段。

📖 天文常用 FITS 关键字段权威速查表

编辑标准卡片时可参考下表，以确保修改内容完全符合 IAU 与 NASA 标准规范：

FITS 关键字 数据类型 推荐标准值示例 科学含义与功能说明
SIMPLE Boolean T 表明文件是否严格符合标准 FITS 规范。必须位于首张卡片。
BITPIX Integer 16 / -32 每像素位深（16 代表无符号/有符号短整数；-32 代表单精度浮点数）。
NAXIS Integer 2 (或 3) 坐标轴数量（2 代表普通 2D 图像；3 代表三维数据立方体或 RGB 阵列）。
OBJECT String 'M42 Orion' 目标天体名称，用于目录编目与后期归档检索。
EXPTIME Float / Number 300.0 总单帧曝光时长，单位恒定为秒（Seconds）。
FILTER String 'Ha', 'OIII' 拍摄该帧时所使用的光学滤镜名称。
BAYERPAT String 'RGGB' / 'BGGR' 色彩滤波阵列排列模式，用于彩色传感器去马赛克插值。
FOCALLEN Float / Number 800.0 望远镜/镜头的有效光学焦距，单位为毫米（mm）。
PIXSIZE Float / Number 3.76 相机感光元件每个像素的物理微米尺寸（μm）。
GAIN Integer / Float 100 拍摄时相机传感器所使用的增益数值。
