⚠️ Common Real-World Scenarios Requiring Header Editing

Whether you capture data with N.I.N.A., ASIAIR, KStars/Ekos, or proprietary observatory software, metadata errors frequently corrupt post-processing pipelines. Below are the most frequent issues experienced astronomers encounter:

❌ Missing or Corrupt BAYERPAT

Color cameras (OSC) require a valid BAYERPAT (e.g. RGGB, BGGR). If missing, Siril or PixInsight produces monochromatic or inverted color images during debayering.

Fix: Add or edit the BAYERPAT keyword to match your sensor's color filter array pattern.

❌ Plate-Solving Failures (WCS / Scale)

Plate solvers (ASTAP, ASTROMETRY.NET) fail when telescope focal length (FOCALLEN) or sensor pixel size (PIXSIZE / XPIXSZ) are zero or incorrectly recorded.

Fix: Correct the exact optical parameters directly in the header table.

❌ Unassigned Filter Metadata in LRGB / SHO

Mono imaging sequences occasionally lose the FILTER tag, causing automated stacking tools to blend Narrowband Ha with Luminance or Red channels.

Fix: Set the exact filter name (e.g., Ha 3nm, OIII, Lum) on all relevant subframes.

❌ Inconsistent Exposure Time (EXPTIME)

When stacking with sigma-clipping or exposure weighting, zero or mismatched EXPTIME values distort signal-to-noise ratio (SNR) algorithms.

Fix: Recalibrate the numeric exposure time in seconds.

📖 Standard Astronomical FITS Keywords Reference Table

Refer to this reference when modifying standard header cards to maintain compatibility with NASA and IAU guidelines:

FITS Keyword Data Type Example Standard Value Scientific Description & Function
SIMPLE Boolean T Indicates whether the file conforms strictly to the standard FITS specification. Must be first card.
BITPIX Integer 16 / -32 Bits per data pixel (16 = unsigned/signed short; -32 = single-precision IEEE float).
NAXIS Integer 2 (or 3) Number of coordinate axes (2 for 2D astronomical image; 3 for datacubes/RGB).
OBJECT String 'M42 Orion Nebula' Target celestial object name for cataloging and project identification.
EXPTIME Float / Number 300.0 Total exposure duration of the observation measured in seconds.
FILTER String 'Ha', 'OIII', 'Luminance' Optical filter utilized during the capture sequence.
BAYERPAT String 'RGGB' / 'BGGR' CFA (Color Filter Array) pattern required for proper debayering.
FOCALLEN Float / Number 800.0 Effective focal length of the telescope/lens optical train in millimeters.
PIXSIZE Float / Number 3.76 Physical pixel pitch of the sensor active area in microns (μm).
GAIN Integer / Float 100 Sensor amplifier gain setting utilized during frame acquisition.
